# Подготовка к 1С:Профессионал — ERP 2.5

Приложение для изучения 761 вопроса по 14 разделам. Интерфейс написан на Vue 3 и TypeScript. Команда сборки создаёт автономный HTML, который можно открыть без интернета и локального сервера, а также ту же страницу для Vercel.

## Возможности

- Выбор любого сочетания разделов, поиск по номеру и тексту, фильтр подтверждения.
- Просмотр ответов из ключа и самопроверка с оценкой выбранного варианта.
- Счёт самопроверки по всей текущей выборке, включая другие страницы. Смена фильтров сохраняет ответы в памяти; смена режима, перезагрузка и «Начать заново» сбрасывают их.
- Перемешивание вопросов, возврат к исходному порядку и пагинация по 20 вопросов.
- Отдельная пометка для неподтверждённых вопросов. Вопросы без ответа доступны для чтения, но не оцениваются.
- Адаптивный интерфейс со сворачиваемым списком разделов на небольших экранах.

## Разработка

Требуется Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
npm run type-check
npm test
npm run build
```

`npm run dev` запускает Vite для разработки. `npm run build` проверяет типы, собирает приложение и создаёт `1C_ERP25_2026_research_answer_key.html` и `public/index.html`. Первый файл можно отправить на устройство и открыть локально. `public/index.html` используется Vercel; настройки находятся в `vercel.json`.

## Структура

- `1C_ERP25_2026_research_answer_key.json` — единственный источник вопросов и ответов. `answer_number: null` означает неизвестный ответ. Поле `confirmed` хранит статус подтверждения учебным тестированием.
- `src/study/core.ts` — проверка данных, фильтрация, перемешивание и оценка.
- `src/study/useStudySession.ts` — состояние текущей подготовки и вычисляемые результаты.
- `src/components/` — компоненты фильтра разделов и вопроса; `src/App.vue` собирает страницу.
- `src/styles/study.css` — оформление и адаптивная вёрстка.
- `scripts/build-standalone.mjs` — упаковка CSS и JS в один HTML.
- `tests/study.test.ts` — проверки сохранности базы, правил подготовки, интерфейса и автономной сборки.

Готовый HTML генерируется из исходников, редактировать его вручную не нужно. Проверка контрольной суммы в тесте фиксирует формулировки и ответы: при намеренном обновлении базы её нужно пересмотреть и обновить контрольную сумму.
