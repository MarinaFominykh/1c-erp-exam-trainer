# Подготовка к 1С:Профессионал — ERP 2.5

Откройте `1C_ERP25_2026_research_answer_key.html` в браузере. Страница работает без интернета, установки зависимостей и локального сервера. Для переноса на телефон достаточно отправить этот HTML-файл и открыть его в браузере, поддерживающем локальные HTML-файлы.

## Возможности

- Просмотр 761 вопроса по 14 разделам; можно выбрать любое сочетание разделов.
- Режим «Показать ответы» выделяет ответ из ключа.
- В режиме «Самопроверка» выбор варианта сразу показывает результат. Кнопка «Показать ответ» открывает ответ без начисления результата.
- Поиск по номеру, тексту вопроса и вариантам; фильтры подтверждения работают вместе с выбором разделов.
- Перемешивание вопросов и возврат к исходному порядку; по 20 вопросов на странице.
- Метка «Не подтвержден» у вопросов без подтверждения учебным тестированием. Если ответ пока неизвестен, вопрос можно прочитать, но нельзя оценить.
- Счёт самопроверки относится ко всей текущей выборке, включая другие страницы. Смена фильтров сохраняет ответы в памяти, смена режима, перезагрузка или «Начать заново» сбрасывает их. История попыток не записывается.
- Адаптивный интерфейс: на небольшом экране разделы свёрнуты и открываются нажатием на заголовок «Разделы».

## Структура и редактирование

- `1C_ERP25_2026_research_answer_key.json` — единственный источник данных. `confirmed` сохраняет прежний статус подтверждения учебным тестированием, включая ранее зафиксированное подтверждение методом исключения. `answer_number: null` означает, что ответ не определён.
- `src/page.html` — шаблон страницы.
- `src/study.css` — оформление и мобильная адаптация.
- `src/study-core.js` — проверка данных, фильтрация, перемешивание и оценка ответа.
- `src/study-app.js` — интерфейс и состояние текущей самопроверки.
- `build.js` — сборка автономного HTML из шаблона, стилей, скриптов и JSON.
- `tests/study.test.js` — проверки сохранности базы и логики подготовки. Это проверки программы, а не история учебных тестирований.

После изменения JSON или файлов в `src` пересоберите страницу (Node.js 18+):

```sh
node build.js
node --test tests/study.test.js
```

Готовый HTML генерируется автоматически; его не нужно редактировать вручную. Зависимостей npm нет. Проверка контрольной суммы фиксирует исходные формулировки и ответы: при намеренном обновлении базы потребуется обновить её в тесте.

## Публикация на Vercel

Сборка также создаёт `public/index.html`. В `vercel.json` заданы команда `npm run build`, выходная папка `public` и тип проекта `Other` (`framework: null`). Подключите репозиторий к Vercel; дополнительные зависимости и переменные окружения не нужны. Папка `public` создаётся при сборке и исключена из Git. На хостинг попадает только готовая страница со встроенными вопросами.
